# Spatial Cluster

Unsupervised discovery of spatial structure/domains from covariates, e.g.
clustering potential-field data into geologically-meaningful domains — the
same task as the original R `SRFGeoTIFF.R` workflow. Do `spatial-data-prep`
first: you need `layers` and `centers` (sampled cells, not full-grid) before
anything here.

## Important: known parity limitation

**Read this before treating output as R-equivalent.** This implementation
approximates `randomForestSRC(distance="all")` by training a classifier to
discriminate real vectorised patterns from synthetic patterns generated by
independently permuting each feature column — the same real-vs-synthetic
mechanism `randomForestSRC` itself uses internally. But empirical validation
against a real R distance matrix (see `.features/PLAN.md`, "Improve
Unsupervised SRF Parity") found only **moderate correlation** (Pearson r ~=
0.35, PAM(k=4) adjusted Rand index ~= 0.29) — confirmed to be a **real
algorithmic gap**, not run-to-run noise (R's own reproducibility on identical
input is r ~= 0.99). This is a deliberate, accepted limitation, not a bug:
treat clustering output as directionally similar to what R would produce,
not numerically interchangeable with it.

## Fit

```python
from spatialized import UnsupervisedSpatialRandomForest

model = UnsupervisedSpatialRandomForest(n_estimators=100, random_state=42)
model.fit(layers, centers, rotations=True)

distance = model.distance_          # center-level distance matrix
```

To feed in patterns already vectorised elsewhere (e.g. recovered R ground
truth, for validation) instead of extracting from rasters, use
`model.fit_prepared(patterns, n_centers=..., rotations=True)`.

## Clustering and diagnostics

```python
clusters = model.spectral_cluster(n_clusters=8)

diagnostics = model.diagnostics(k_values=range(2, 11))
diagnostics.silhouette_scores   # per k
diagnostics.eigengaps           # per k, for eigengap-based k selection

embedding = model.mds(n_components=2)   # for 2D visualisation
```

Map sampled-cluster labels back to a raster with `grid_from_centers(shape,
centers, clusters, fill_value=-1)`.

## Full-grid domain prediction

The workflow-level helper trains a supervised classifier on the sampled
cluster labels, then predicts domains (and entropy) over every valid cell:

```python
from spatialized import predict_unsupervised_domains

result = predict_unsupervised_domains(
    layers, centers, full_grid_mask,
    n_clusters=8, rotations=True,
)
```

**Be aware of scale.** The real R workflow's full-grid prediction step, run
over an ~11.3M-cell raster, was estimated to take on the order of a full day
of compute even in R — this isn't a Python-specific problem, it's inherent
to dense per-cell prediction at that resolution. Consider chunking,
subsetting to a region of interest, or accepting sampled-domain output only
(skip full-grid prediction) for large rasters.
